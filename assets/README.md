## Logo File

The SC Connections logo is at: `sc-connections-logo.svg`

Current specifications:
- Format: SVG (Scalable Vector Graphics)
- Dimensions: 200x50 viewBox
- Clean design with SC branding and "Connections" text

To replace with a custom logo:
- Use SVG format for best quality at all sizes
- Alternative: PNG with transparent background, 200x50 pixels (or 2x for retina: 400x100)
- Keep file size < 50KB for fast loading
