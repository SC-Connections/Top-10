## 🐛 Troubleshooting

### Workflow fails with "RAPIDAPI_KEY not set"

**Solution**: Add `RAPIDAPI_KEY` secret in repository Settings → Secrets

### Workflow fails with "No products found"

**Causes**:
- API rate limit exceeded
- No products match criteria
- API connectivity issues

**Solution**: Wait and retry, or check API status

### Site not updating

**Check**:
1. Workflow is enabled (Actions tab)
2. Scheduled workflows are not disabled
3. No branch protection blocking pushes

### Pages not deploying

**Check**:
1. Settings → Pages → Source is "GitHub Actions"
2. Workflow has `pages: write` permission
3. Deployment completed successfully
